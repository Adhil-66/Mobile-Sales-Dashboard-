# Mobile-Sales-Dashboard-
📱 Mobile Sales Dashboard

📌 Project Overview

The Mobile Sales Dashboard is an interactive Excel dashboard designed to analyze mobile phone sales performance. It provides insights into revenue, units sold, customer ratings, brand performance, and city-wise sales to support data-driven business decisions.

🎯 Project Domain

Sales Analytics & Business Intelligence (Retail).

🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization

📊 Dashboard Highlights

- Total Revenue: ₹76,92,04,987.97
- Total Units Sold: 19,150
- Average Customer Rating: 3.69

📈 Key Features

- Year-wise revenue analysis.
- Top 5 cities by sales.
- Brand-wise sales performance.
- Top 5 mobile models by revenue.
- Customer ratings by mobile brand.
- Units sold by mobile brand.
- Interactive filters for Brand, Year, and City.

💡 Key Insights

- Identify the highest-revenue mobile brands.
- Analyze sales trends across different years.
- Identify top-performing cities.
- Compare customer ratings across brands.
- Understand mobile brand sales distribution.

🎯 Project Objective

To transform raw mobile sales data into meaningful business insights through an interactive Excel dashboard, helping businesses monitor performance and make informed decisions.
